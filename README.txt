FREE PUBLISHING OPTION (GitHub Pages)
1. Create/sign in to a GitHub account at https://github.com
2. Create a new public repository (for example: laiba-m-studio-app).
3. Upload all files in this folder to the repository root.
4. Open repository Settings > Pages.
5. Choose deploy from branch, select main and /(root), then Save.
6. Wait for the published HTTPS link. Open that link on your phone.
7. Android: browser menu > Install app or Add to Home screen. iPhone: Safari Share > Add to Home Screen.
